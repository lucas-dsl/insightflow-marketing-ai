# InsightFlow Marketing AI

> **Transformando dados de marketing em insights criativos acionáveis.**

## 📌 Visão do projeto

O **InsightFlow Marketing AI** é um MVP mobile-first criado para resolver uma dor comum em times de marketing: **ter muitos dados, mas dificuldade em transformá-los em decisões estratégicas e ideias criativas**.

A proposta do produto é unir **dados internos da empresa** (campanhas, leads, conversões, receita) com **tendências externas de mercado** para gerar recomendações inteligentes sobre os próximos passos.

Mais do que apenas dashboards, a plataforma foi idealizada como um **assistente estratégico para equipes de marketing**, capaz de traduzir números em hipóteses, oportunidades e ações criativas.

---

## 🚀 Problema resolvido

Times de marketing normalmente possuem acesso a diversos indicadores:

* CTR
* CPL
* Conversões
* Receita
* Performance por canal
* Tendências do mercado

O desafio não está em visualizar os números, mas em responder perguntas como:

* **O que esses dados significam?**
* **Qual canal merece mais investimento?**
* **Que tipo de criativo devo testar?**
* **O mercado está se movendo para qual direção?**

O InsightFlow resolve isso transformando dados em **insights criativos e acionáveis**.

---

## 🧠 Proposta de valor

A ideia central do MVP é simples e poderosa:

> **usar inteligência para cruzar performance interna com contexto externo e sugerir a próxima melhor ação de marketing.**

Exemplos de insights gerados:

* queda de CTR + tendência de vídeos curtos em alta
* aumento de CPL + oportunidade em creators
* canal com melhor conversão + sugestão de escala
* oportunidade de testes A/B baseada em comportamento do mercado

---

## 📱 Principais funcionalidades

### 📂 Upload de CSV

Permite importar dados reais da empresa com colunas como:

* data
* canal
* campanha
* investimento
* cliques
* leads
* conversões
* receita

Também possui CSVs de exemplo para testes e demonstração.

### 📊 Dashboard de performance

Visualização dos principais KPIs de marketing:

* performance por canal
* campanhas
* conversões
* receita
* eficiência de mídia

### 📈 Tendências externas de mercado

Integração com tendências reais utilizando:

* **Supabase Edge Functions**
* **SerpApi (Google Trends)**

Essas tendências enriquecem o contexto estratégico do time.

### 💡 Motor dinâmico de insights

O diferencial do produto.

Um mecanismo de regras cruza:

* dados internos
* tendências externas
* comportamento por canal

para gerar:

* problema detectado
* oportunidade
* ação recomendada
* ideia criativa
* prioridade
